# Talklog

학습 짝과 비동기 음성 메시지를 주고받으며 외국어 표현을 자연스럽게 학습하는 모바일 우선 프로토타입입니다.

대화 중 들은 음성을 확인하고, 스크립트와 번역을 필요할 때만 열어본 뒤, 스크립트에서 배우고 싶은 표현을 골라 카드로 저장하고 복습하는 흐름을 검증하기 위해 제작했습니다.

## 주요 기능

- 진행 중인 학습방과 오늘의 복습 현황 확인
- 학습방 목록·개설·확인 후 삭제, 학습 짝·학습 언어 구분과 최근 활동 순 홈 요약
- 학습방 정보의 브라우저 저장소 보관, 학습방별 녹음 메시지 분리
- 학습 짝과 내가 보낸 음성 메시지 UI
- 학습 짝 음성의 스크립트와 번역을 각각 독립적으로 열고 닫기
- 실제 음성 녹음(최대 60초)과 재생
- 보내기 전 미리 듣기·다시 녹음·취소, 명시적인 전송 단계
- 마이크 권한 거부·장치 없음·미지원 상황별 안내
- 예시 스크립트와 다듬은 문장을 비교하는 AI 피드백 화면 (Mock)
- 스크립트에서 배우고 싶은 범위를 직접 골라 뜻을 적어 표현으로 저장 (끌어서 고르기 · 터치 롱프레스 · `Shift`+방향키가 모두 같은 경로)
- 저장한 표현을 브라우저 저장소에 보관하고 카드 목록에서 확인 (뜻 · 예문 · 출처 학습방)
- 같은 표현의 중복 저장 차단, 확인 단계를 거치는 표현 삭제
- 오늘 예정된 저장 표현을 최대 20장씩 복습하고 뜻·예문·출처를 확인한 뒤 기억 여부 기록
- 응답 즉시 저장, 간격 반복(1→2→4→최대 30일), 다시 볼 카드 한 번 재등장
- 복습 완료 결과와 홈의 실제 표현 수·오늘 대상 수·누적 복습 정답률
- 카드 목록 항목에서 표현·뜻 편집과 취소, 예문·출처·저장 순서 보존, 중복 검사와 저장 실패 후 재시도
- 모바일 우선 반응형 레이아웃 및 키보드 접근성 속성

## 사용자 흐름

```text
홈
 ├─ 진행 중인 학습방
 │   └─ 음성 메시지 확인
 │       ├─ 스크립트 토글
 │       │   └─ 배우고 싶은 범위 고르기
 │       │       └─ 표현 다듬기 → 뜻 적기 → 카드에 저장
 │       ├─ 번역 토글
 │       ├─ 음성 답장 녹음
 │       │   └─ 미리 듣기 → 다시 녹음 / 전송
 │       └─ AI 피드백
 │           └─ 표현 저장
 ├─ 내 표현
 │   └─ 저장한 표현 목록 · 편집 · 삭제
 └─ 오늘의 복습
     └─ 카드 뒤집기
         └─ 기억 여부 선택 → 다시 볼 카드 한 번 더 → 복습 완료 → 홈 / 학습방
```

## 기술 스택

- Next.js 15
- React 19
- TypeScript 5
- Tailwind CSS 4
- MediaRecorder · getUserMedia (브라우저 표준 API, 추가 의존성 없음)
- CSS 기반 반응형 UI

## 시작하기

### 요구 사항

- Node.js 20 이상
- npm

### 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인합니다.

Windows PowerShell의 실행 정책으로 `npm` 명령이 차단될 경우 다음처럼 실행할 수 있습니다.

```powershell
npm.cmd install
npm.cmd run dev
```

### 프로덕션 빌드

```bash
npm run build
npm run start
```

## Vercel 배포

Git 저장소를 Vercel에 연결한 뒤 프로젝트를 가져오면 Next.js 설정이 자동으로 감지됩니다. 별도의 환경 변수나 빌드 설정은 현재 필요하지 않습니다.

Vercel CLI를 사용하는 경우에는 프로젝트 루트에서 다음 명령을 실행합니다.

```bash
npx vercel
```

공개 배포 전에는 `package.json`의 Next.js를 최신 보안 패치 버전으로 올리고 빌드 결과를 다시 확인하는 것을 권장합니다.

## 현재 구현 범위

이 프로젝트는 사용자 흐름을 검증하기 위한 프론트엔드 프로토타입입니다. 실제 기능과 예시·미구현 범위는 다음과 같습니다.

- **표현 저장·카드 편집**: 스크립트에서 직접 고르거나 예시 피드백에서 저장합니다. 카드 목록에서 표현 본문·뜻을 편집하고 삭제할 수 있습니다. 편집은 예문·출처 학습방·저장 시각·순서를 보존하며 중복을 검사합니다. 저장 실패 때 입력을 유지해 재시도할 수 있습니다. 표현은 `localStorage`에 남아 새로고침 후에도 유지됩니다.
- **복습**: `talklog.reviews`에 기억 여부·다음 시점·누적 응답 수를 저장합니다. 기기 로컬 날짜를 기준으로 응답마다 저장하므로 중간에 나가도 기록이 남습니다. 완료 통계는 카드별 최종 응답, 누적 정답률은 재등장을 포함한 모든 응답 기준입니다. 홈은 실제 표현 수·복습 대상 수·누적 정답률을 표시하며, 데이터가 없는 대화한 날 통계는 제거했습니다.
- **음성**: 실제 녹음·미리 듣기·재생과 전송 전 확인이 동작합니다. 녹음 메시지는 학습방별 브라우저 메모리에만 보관하므로 새로고침하면 사라집니다.
- **공통 셸**: 홈 날짜는 기기의 로컬 날짜이며 자정과 탭 복귀 시 갱신됩니다. 인사는 시간 중립 문구입니다. 계정·설정이 없으므로 프로필·마이 메뉴는 제공하지 않습니다.

학습방 목록·개설·삭제는 실제로 동작합니다. 학습 짝 이름(1~20자)과 일본어·영어·중국어 중 학습 언어를 정해 개설하며, 학습방 정보는 `localStorage`의 `talklog.rooms`에 남습니다. 홈에는 최근 활동 순 최대 3개가 보이고, 대화 메뉴에서 전체 목록을 엽니다. 삭제에는 확인 단계가 있고 저장한 표현은 지우지 않습니다. 저장소 오류는 안내와 재시도를 제공하며 성공한 것처럼 표시하지 않습니다.

“유키와 일본어 대화”는 삭제할 수 없는 예시 학습방입니다. 예시 스크립트·번역·피드백은 이 학습방에만 있습니다. 예시 음성 메시지에는 재생할 소리가 없어 재생 버튼이 비활성입니다. AI 피드백의 스크립트·다듬은 문장은 Mock임을 화면에 표시하며, 카드 저장은 실제 저장 경로를 씁니다. 새 학습방은 비어 있는 상태에서 실제 녹음을 시작할 수 있습니다.

동시 탭 쓰기의 원자성 및 기기 간 동기화는 제공하지 않습니다.

다음 기능은 미구현입니다. 스크립트·번역·AI 피드백에는 예시 화면만 제공합니다.

- 회원가입과 로그인
- 음성 메시지 업로드와 서버 보관
- STT 변환
- AI 문장 다듬기와 번역
- 알림, 학습 짝 초대 및 실시간 통신
- API, 서버 및 데이터베이스

## 향후 확장 방향
