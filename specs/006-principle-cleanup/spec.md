## User Scenarios & Testing

### User Story 1 — 믿을 수 있는 공통 화면 (Priority: P1)

사용자는 앱을 열어 오늘 날짜와 실제 기록을 보고, 동작하는 메뉴로 다음 행동을 선택한다.

**Why this priority**: 미구현 기능과 고정 수치는 사용자 흐름 검증을 왜곡한다.
**Independent Test**: 홈과 공통 메뉴를 확인하고 학습방·카드·복습을 오간다.

**Acceptance Scenarios**:

1. **Given** 어느 화면에서든, **When** 공통 메뉴를 확인하면, **Then** 미구현 프로필·마이·더 보기 컨트롤이 없다.
2. **Given** 기기의 날짜가 바뀌면, **When** 홈에 머물거나 다시 돌아오면, **Then** 로컬 날짜가 표시되고 특정 시간대나 사용자 이름을 가정하지 않는다.
3. **Given** 저장한 기록이 없거나 저장소가 차단되면, **When** 홈을 열면, **Then** 기존 빈 상태·실패 안내가 보이고 고정 통계가 실제 기록처럼 보이지 않는다.
4. **Given** 예시 학습방을 열면, **When** 메시지와 피드백을 확인하면, **Then** 예시 콘텐츠임을 구별할 수 있고 실제 저장·녹음 경로는 유지된다.

### User Story 2 — 일관된 언어와 화면 (Priority: P2)

사용자와 개발자는 같은 개념을 같은 용어로 이해하고, 기존 화면 색상과 기능을 유지한다.

**Why this priority**: 문서와 화면의 의미가 일치해야 검증 결과를 신뢰할 수 있다.
**Independent Test**: 용어집과 코드·README·003~005 문서를 대조하고 스타일 값과 구현 현황을 확인한다.

**Acceptance Scenarios**:

1. **Given** 용어집을 기준으로, **When** 대상 코드·문서를 검색하면, **Then** 금지 용어의 개념 대체 사용이 없다.
2. **Given** 기존 화면 색상을 기준으로, **When** 정리 후 화면을 보면, **Then** 모든 색상이 동일하다.
3. **Given** 현재 구현을 기준으로, **When** README와 도메인 지도를 읽으면, **Then** 002~005의 실제 범위·예시·미구현·저장 한계가 구분된다.

### Edge Cases

- 최초 렌더에서는 날짜를 확정하지 않고 기기에서 확인한 뒤 표시한다. 자정·탭 복귀 시 갱신한다.
- 예시 메시지 시각·길이·내용은 예시 표시가 있으므로 유지한다. 실제 메시지 수·시각·복습 수는 기존 데이터 경로를 쓴다.
- 문장 부호·언어 범주 설명과 금지 용어 사용 금지 주석, 브라우저 표준 식별자는 용어 위반에서 제외한다.
- 저장소 읽기·쓰기 실패, 빈 목록, 삭제 확인·취소·포커스 이동은 기존 동작을 보존한다.

## Requirements

### Functional Requirements

- **FR-001**: 미구현 공통 컨트롤을 제거하고 남은 메뉴는 키보드로 조작 가능해야 한다.
- **FR-002**: 홈은 기기 로컬 날짜와 시간 중립 인사를 표시하고 고정 사용자 신원을 가정하지 않아야 한다.
- **FR-003**: 전 화면 수치·시각은 실제 데이터이거나 예시임이 식별되어야 한다.
- **FR-004**: `app/`, `README.md`, `specs/003~005`는 용어집을 준수하고 001·002 문서는 수정하지 않아야 한다.
- **FR-005**: 스타일의 색상 정의는 공통 변수에 모으고 기존 색상값을 보존해야 한다.
- **FR-006**: 도메인 지도의 구현 상태·다음 작업·드리프트와 README의 기능·구조·구현 범위를 현재로 동기화해야 한다.
- **FR-007**: 기존 표현 저장·편집·삭제, 복습, 학습방 개설·삭제, 녹음·재생 및 오류·확인 경로를 보존해야 한다.

## Success Criteria

- **SC-001**: 전 화면에 동작하는 것처럼 보이는 미구현 공통 컨트롤이 0개다.
- **SC-002**: 홈의 날짜가 기기 로컬 날짜와 일치하고 고정 통계·신원·시간대 인사가 0개다.
- **SC-003**: 대상의 용어 위반과 기존 색상 변경이 0개다.
- **SC-004**: README와 도메인 지도가 실제 기능과 예시·미구현 범위를 모두 설명한다.
- **SC-005**: 기존 주요 흐름을 그대로 수행할 수 있다.

## Assumptions

- 계정·설정은 구현하지 않는다. 필요 없는 프로필·마이 메뉴를 제거한다.
- 날짜 표시는 한국어 형식을 사용하며 기기 시간대를 따른다.
- 새 의존성·저장 데이터·삭제 동작은 추가하지 않는다. 브라우저 수용 검증은 별도 검증자가 수행한다.
