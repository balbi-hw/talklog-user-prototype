# Quickstart: 공통 셸 원칙 정리 검증

**Feature**: [spec.md](./spec.md) | **Tasks**: [tasks.md](./tasks.md) | **Date**: 2026-10-27

## 실행과 사전 조건

Node.js 20 이상에서 `npm.cmd run dev`로 실행한다. 빌드 게이트는 `npm.cmd run build`다.
기존 데이터를 보존하려면 별도 브라우저 프로필에서 빈 저장소·차단 시나리오를 수행한다.
브라우저 시나리오는 별도 검증자에게 전달하며 이 작업에서 실행했다고 간주하지 않는다.

## 실행 기록과 범위

- `setup-tasks.ps1 -Json`과 `check-prerequisites.ps1 -Json -RequireTasks -IncludeTasks`는 006 경로를 정상 해석했으나 plan 필수 검사에서 종료했다. 006 브리프가 plan 생략을 명시하므로 스크립트는 수정하지 않고 spec·tasks·기술 제약을 직접 검토했다.
- 명세 품질 검토: 사용자 가치·독립 스토리·수용 기준·측정 가능한 성공 기준·예외·범위·전제 확인. 모호함 표식 없음. 006 브리프대로 별도 checklist 파일 없이 세 문서만 작성했다. 확장 훅 파일 없음.
- `npm.cmd run build`: 최종 실행 종료 코드 0, 컴파일·타입 검사·정적 페이지 4개 생성 통과, CSS 최적화 경고 없음. 최초 빌드에서 색상 치환이 `white-space` 속성명에 영향을 준 경고를 발견해 복구한 뒤 재빌드했다.
- CSS 변수 전개 대조: 기존 CSS와 색상값·나머지 선언 동일. 의도한 차이는 학습 짝 클래스명과 하단 메뉴 4열→3열뿐이다. `:root` 밖의 직접 색상값 0개. 기존 7개 변수 재사용, 추가 색상 토큰 81개(white·transparent 포함), 같은 색은 같은 변수 사용.
- 전체 app 버튼 정적 구문 검사: 네이티브 버튼 정의 50개 모두 클릭 핸들러 또는 명시적인 폼 submit 경로 존재. 콜백 연결·비활성 예시 재생도 코드 대조했다. 고정 홈 날짜·신원·시간대 인사·가짜 메시지 수·상대 시각·무동작 메뉴 잔존 없음.
- 날짜 컴포넌트 메모리 실행 검사: React 훅·기기 시계를 대체해 서울·뉴욕에서 최초 렌더, 로컬 날짜, 연말 자정, 윤일, focus·visibilitychange 갱신, 타이머·리스너 정리 통과. 실제 브라우저 검증과는 구분한다.
- 용어 검색: app의 사용 금지 설명 주석과 언어 범주 설명만 남음. README·003~005 문서 위반 없음. 001·002 및 기존 저장·편집·복습·학습방·녹음 로직 파일 변경 없음. `git diff --check` 통과.
- `.specify/feature.json`은 저장소의 기존 ignore 대상이며 로컬에서 006 경로를 지정했다. 브랜치 변경·커밋·push 없음.
- S1~S4 브라우저 조작·시각 비교는 미실행이며 별도 검증자 확인 대상이다.
