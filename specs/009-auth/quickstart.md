# Quickstart: 로그인

## 준비
- `.env.local` 에 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
- Supabase 대시보드 **Authentication → URL Configuration**: Site URL `http://localhost:3000`, Redirect URLs 에 `http://localhost:3000/auth/confirm`.
- `npm.cmd run build` → `npm.cmd run start`.

## 참고
- Supabase 기본 메일 서버는 시간당 발송 수가 적고, 프로젝트 팀원이 아닌 주소로는 보내지 않을 수 있다. 개발 중에는 Confirm email 을 끄거나 사용자 SMTP 를 설정한다.
