# Quickstart

## 키 없이 Mock
1. npm.cmd run build, npm.cmd run dev. 키 없이 자동 Mock 또는 REFINEMENT_PROVIDER=mock.
2. 학습방에서 내 음성을 녹음·전송. 스크립트 준비 전 다듬기 비활성과 이유 확인.
3. 스크립트를 열어 준비 후 다듬기 열기. 문장·한국어 이유·예시 표시 확인.
4. Network 패널에서 닫고 3회 재열기·화면 이동 복귀에 추가 요청 0회 확인.
5. 결과 전체와 일부를 마우스·키보드로 선택, 뜻을 적어 저장. 내 표현에서 예문 전체·해당 학습방 출처 확인. 중복·저장소 실패는 002와 동일.
6. 네트워크 offline 요청 실패 후 연결 복구·다시 시도. 지연 중 재생·답장·스크립트 표현 저장이 가능해야 한다.
7. 응답 대체로 504/429/503/502 및 잘못된 JSON을 주어 상태·재시도 확인. changed=false는 정상 안내, 빈 문장은 실패.
8. 스크립트 재요청·메시지 삭제 중 늦은 응답은 무시. 현재 UI는 성공 스크립트 재요청을 노출하지 않으므로 훅 경계에서 검증.
9. 예시 학습방 배너의 Feedback은 여전히 예시. 학습 짝 메시지에는 실제 다듬기 없음.

## 키 필요 (별도 검증)
ANTHROPIC_API_KEY, REFINEMENT_PROVIDER=claude, 필요 시 REFINEMENT_MODEL 설정. 실제 STT도 OPENAI_API_KEY 필요.
일본어·영어·중국어에서 문장·한국어 이유·변경 없음·실제 표시 확인. 의도적으로 깨진 제공자 JSON/토큰 중단은 failed.
실제 키 호출은 이번 범위에서 실행하지 않는다.
