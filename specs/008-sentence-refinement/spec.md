# Feature Specification: 실제 문장 다듬기

**Feature Branch**: `008-sentence-refinement` | **Created**: 2026-10-29 | **Status**: Approved for implementation
**Input**: 008 우선 브리프. 공통 브리프는 지정 경로에 없어 저장소 절차 적용.
**서브도메인**: 표현 학습 (Core). **흐름**: draft.md §4의 7·11단계.

## User Scenarios & Testing

### User Story 1 - 내 문장 다듬기 (Priority: P1)

내가 녹음해 보낸 음성 메시지의 준비된 스크립트 가까이에서 다듬은 문장과 짧은 한국어 이유를 확인한다.
**Why this priority**: 내 대화에서 표현을 발견하는 시작점이다.
**Independent Test**: 녹음·전송 후 스크립트를 열고 다듬기를 연다.

**Acceptance Scenarios**:
1. **Given** 준비된 내 스크립트, **When** 다듬기 최초 열기, **Then** 처리 상태 후 다듬은 문장·이유·실제/예시 구분을 본다.
2. **Given** 스크립트 없음, **When** 메시지 보기, **Then** 요청 불가 이유가 보인다.
3. **Given** 이미 자연스러운 스크립트, **When** 다듬기 완료, **Then** 그대로도 자연스러움을 정상 결과로 알리고 문장도 보인다.
4. **Given** 같은 결과, **When** 닫고 다시 열거나 화면 이동 후 복귀, **Then** 추가 요청 없이 재사용한다.

### User Story 2 - 실패 후에도 대화 계속 (Priority: P2)

**Why this priority**: AI가 대화를 가로막으면 안 된다.
**Independent Test**: 통신을 끊거나 응답을 지연시키고 기본 행동·재시도를 확인한다.

**Acceptance Scenarios**:
1. **Given** 처리 중, **When** 재생·답장·스크립트 보기·표현 저장, **Then** 모두 계속 가능하다.
2. **Given** 실패·시간 초과·사용 한도 초과·네트워크 끊김, **When** 결과 확인, **Then** 원본을 유지하고 해당 안내·다시 시도를 제공한다.
3. **Given** 스크립트 재시도 또는 메시지 삭제, **When** 이전 응답 도착, **Then** 오래된 결과를 표시하지 않는다.

### User Story 3 - 다듬은 문장을 표현으로 (Priority: P3)

**Why this priority**: Core 흐름을 카드까지 연결한다.
**Independent Test**: 결과의 전체 또는 일부를 선택해 뜻을 입력하고 저장 후 내 표현에서 확인한다.

**Acceptance Scenarios**:
1. **Given** 다듬은 문장, **When** 전체/일부를 저장, **Then** 예문은 다듬은 문장 전체이고 출처는 해당 학습방이다.
2. **Given** 중복·저장소 실패, **When** 저장, **Then** 기존 저장 경로의 안내와 입력 보존을 따른다.

### Edge Cases

빈 문장·깨진 응답은 실패이며 바꿀 것 없음과 구분한다. 빠른 재열기는 중복 요청하지 않는다.
예시 입력 기반 결과도 예시다. 예시 학습방 피드백은 예시로 유지한다. 학습 짝 메시지는 대상이 아니다.

## Requirements

### Functional Requirements

- **FR-001**: 내가 녹음한 메시지의 준비된 스크립트만 다듬는다. 준비 전 요청을 막고 이유를 안내한다.
- **FR-002**: 다듬은 문장·짧은 한국어 이유와 바꿀 것 없음 정상 결과를 제공한다.
- **FR-003**: 최초 열기만 요청하고 결과는 메시지별 재사용한다. 스크립트 변경·삭제 시 무효화한다.
- **FR-004**: 대기·처리 중·성공·바꿀 것 없음·실패·시간 초과·사용 한도 초과·네트워크 끊김과 명시적 재시도를 제공한다.
- **FR-005**: 모든 상태에서 재생·답장·스크립트 보기·기존 표현 저장을 막지 않는다.
- **FR-006**: 다듬은 문장 전체/일부를 기존 표현 저장 흐름으로 저장한다. 예문·출처를 유지한다.
- **FR-007**: 예시와 실제 결과를 구분하고 예시 학습방의 고정 피드백을 보존한다.
- **FR-008**: 요청 전 외부 전송 가능성과 앱의 학습·평가용 미보관을 안내한다.
- **FR-009**: 키보드 조작·접힘 상태·처리 상태 알림을 제공한다.

### Key Entities

- 메시지별 다듬기: 입력 스크립트·학습 언어, 처리 상태, 다듬은 문장·이유·변경 여부·실제/예시 출처.
- 표현: 선택한 전체/일부, 사용자가 적은 뜻, 전체 다듬은 문장 예문, 학습방 출처.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 준비된 내 스크립트에서 한 번의 열기로 문장과 이유를 확인한다.
- **SC-002**: 같은 메시지를 3회 재열어도 추가 요청은 0회다.
- **SC-003**: 네 가지 오류 상황 모두 원본·기본 행동·재시도를 유지한다.
- **SC-004**: 전체와 일부 각각 저장 후 예문·출처를 100% 보존한다.
- **SC-005**: 키 없는 예시 결과와 예시 학습방 피드백 모두 예시 표시를 갖는다.

## Assumptions

007의 스크립트·언어와 002의 저장 경로를 사용한다. 로그인·수신·메시지 영속화·발음 평가는 범위 밖이다.
실제 키 검증은 키 발급 후 별도 수행한다.

## Clarifications

변경 없음 정상 결과, 최초 열기 요청·메모리 재사용·입력 변경 무효화, 기존 저장 경로,
Mock 표시·외부 전송 안내·미보관. 추가 질문 없음.
