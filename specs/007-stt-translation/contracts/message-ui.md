# 메시지 UI 계약

1. 녹음 아래 스크립트·번역 토글과 고유 aria-controls/expanded를 제공한다.
2. 최초 열기에만 요청. 처리 중 닫기·재생·답장·다른 메시지 열기 가능.
3. 스크립트 success 전 번역 비활성과 이유 안내. 캐시가 있으면 스크립트를 닫아도 번역 가능.
4. role=status에 상태 안내, 오류·빈 결과 재시도. 처리 중에도 재시도 버튼은 자리에 남는다.
5. mock은 예시이며 실제 음성을 분석한 내용이 아님을, real은 실제 결과임을 표시한다.
6. 예시 메시지의 고정 텍스트와 AI 피드백 예시 표시 유지.
7. 002 키보드 선택·표현 저장 재사용, 저장/취소 후 스크립트 포커스 복귀.
8. 입력 id 고유화, 저장 실패 시 초안 유지. 음성은 AI 상태와 무관하게 보존.
9. 최초 요청 자리에서 음성·텍스트의 외부 전송과 앱의 학습·평가 목적 보관 없음을 안내한다.
