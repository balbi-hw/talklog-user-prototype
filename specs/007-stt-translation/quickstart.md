# Quickstart: 실제 스크립트·번역

## 준비

Node 20+, `npm.cmd install`, `npm.cmd run dev`, localhost:3000. 키 없이 Mock으로 전 경로 확인 가능.
마이크 허용 후 1~60초 녹음·전송. 새로고침하면 음성과 결과가 사라진다.
아래는 별도 검증자가 수행할 브라우저 수동 검증이다.

## 키 불필요

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| S1 | 예시 학습방의 예시 메시지 스크립트·번역 열기 | 기존 고정 내용과 예시 표시 |
| S2 | 내 음성 녹음·전송 → 스크립트 열기 | 전송 안내, 처리 중, 예시 결과. 실제 분석이 아니라는 안내 |
| S3 | 스크립트 닫기·재열기·홈 왕복 | 같은 결과 재사용, Network에서 추가 POST 없음 |
| S4 | 스크립트 전 번역, 준비 후 번역 열기 | 먼저 스크립트 안내 → 한국어 예시 결과 → 재열기 캐시 |
| S5 | 일본어·영어·중국어 학습방 각각 만들고 S2~4 | 해당 언어 예시 스크립트와 한국어 번역 |
| S6 | Network Slow 3G에서 메시지 두 개 열기, 재생·답장 녹음 | 각각 처리, 기본 행동 계속 가능 |
| S7 | 스크립트 선택 → 표현 저장 → 뜻 → 저장 → 카드 | 해당 스크립트 예문·학습방 출처, 새로고침 후 카드 유지 |
| S8 | 키보드 Tab·Enter로 토글, 스크립트 Shift+방향키 선택, 저장·취소 | 선택·저장 가능, 완료/취소 후 스크립트 포커스 |
| S9 | 서로 다른 스크립트 저장 폼 두 개 열기 | label이 각 입력을 가리키며 id 충돌 없음 |
| S10 | DevTools Offline 후 미요청 메시지 열기, Online 후 재시도 | 네트워크 끊김 → 재시도 성공. 음성 보존 |
| S11 | Network 응답 재정의로 error.code timeout/limit/failed/network 주입 | 각각 별도 안내·재시도, 음성 재생 가능 |
| S12 | 성공 응답 text를 공백으로 재정의 → 재시도 | 말소리 없음 안내·재시도 |
| S13 | 응답을 40초 이상 지연 | 시간 초과, 재시도 가능 |
| S14 | 진행 중 홈 이동·복귀, 학습방 삭제 후 새 학습방 | 이동은 결과 유지, 삭제는 요청 취소·관련 결과 제거 |
| S15 | 직접 API 호출: 잘못된 언어·MIME, 8MiB 초과, 8,001자 번역 | 400/415/413/400, 외부 전송 안 함 |
| S16 | 1분 안에 요청 21회 또는 동시 5회 | 429 limit. 잠시 후 재시도 가능 |
| S17 | AI 피드백 열기 | 예시 표시 유지, 실제 AI 분석처럼 표시하지 않음 |

S11~13은 DevTools 응답 재정의 또는 로컬 HTTP 프록시로 계약의 JSON을 주입한다. Mock 기본 응답은 성공이며
실패를 재현하기 위해 공개 API에 테스트 전용 제어 필드는 추가하지 않는다.

## 키 필요: 실제 제공자

`.env.example` 변수 이름을 `.env.local`에 복사한다. OPENAI_API_KEY·ANTHROPIC_API_KEY를 설정하고
TRANSCRIPT_PROVIDER=openai, TRANSLATION_PROVIDER=claude로 서버 재시작. 모델 변수는 비워두면 브리프 기본값.

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| R1 | 각 언어로 녹음하고 스크립트 열기 | 실제 발화의 스크립트, 실제 결과 표시 |
| R2 | 번역 열고 실제 스크립트에서 표현 저장 | 한국어 번역, 실제 스크립트 예문·학습방 출처 |
| R3 | 한 제공자만 키를 제거하고 재시작 | 해당 결과만 예시, 예시 스크립트 기반 번역도 예시 |
| R4 | 잘못된 키/모델, 제공자 429 응답 | 실패/한도 안내, 원래 음성 유지, 자동 Mock 위장 없음 |

## 완료 확인

키 없이 `npm.cmd run build` 성공이 필수다. 실제 제공자 품질과 브라우저 수동 시나리오는 실행 여부를 별도로 보고한다.

### 구현 검증 기록 (2026-10-28)

- 키 없는 프로덕션 build 성공, TypeScript 오류 0.
- 프로덕션 서버 API 21회 검사 통과: 3개 언어 Mock 스크립트·번역, no-store,
  잘못된 언어·출처·공백·8,001자 입력, MIME, 업로드/JSON 크기, 잘못된 JSON, 전역 요청 제한.
- 제공자 fetch 대체 계약 검사 통과: 요청 필드·파일 확장자·언어, 오류 402/429/408/504/401/500,
  잘못된 응답, 잘린 번역 거절, 통신 오류 비밀 제거, 서버 시간 상한, 동시 4개 제한, 키 부재 Mock.
- 화면·도메인의 제공자/모델 참조 없음, .env/.env.local 차단과 .env.example 허용 확인.
- 브라우저 수동 S1~17 및 실제 제공자 R1~4는 미실행. 별도 검증자 및 키가 필요하다.
