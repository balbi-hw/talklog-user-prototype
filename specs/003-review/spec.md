**Input**: 저장한 표현으로 오늘의 복습을 진행하고 기억 여부에 따라 다음 복습 시점을 정한다.
홈의 고정 숫자를 실제 기록으로 바꾸고 복습 완료 후 다음 행동을 제공한다.

## User Scenarios & Testing

### User Story 1 - 오늘의 카드 복습 (Priority: P1)

저장한 표현을 앞면으로 보고, 뜻을 확인한 뒤 기억 여부를 기록한다.
**Why this priority**: 저장한 표현이 기억으로 이어지는 13단계를 완성한다.
**Independent Test**: 표현 두 개를 저장한 뒤 복습하고 새로고침하여 다음 복습 시점을 확인한다.

**Acceptance Scenarios**:

1. **Given** 새 표현이 있을 때, **When** 복습을 시작하면, **Then** 표현이 앞면에 나타난다.
2. **Given** 앞면을 보고 있을 때, **When** 뜻 보기를 누르면, **Then** 뜻·예문·출처 학습방이 나타나고 기억 여부를 선택할 수 있다.
3. **Given** 뒤집힌 카드가 있을 때, **When** 알고 있어요를 누르면, **Then** 응답이 즉시 저장되고 다음 카드로 이동한다.
4. **Given** 첫 순회 중일 때, **When** 다시 볼래요를 누르면, **Then** 세션 끝에 해당 카드가 한 번 더 나온다. 재등장 후 다시 볼래요를 눌러도 세션은 끝난다.
5. **Given** 일부 응답을 마쳤을 때, **When** 복습에서 나갔다 돌아오거나 새로고침하면, **Then** 저장한 응답은 남고 미응답에는 기록이 없다.

### User Story 2 - 결과와 다음 행동 (Priority: P2)

복습한 카드 수와 기억 여부를 확인하고 홈 또는 학습방으로 돌아간다.
**Why this priority**: 14단계에서 복습을 닫고 다음 흐름을 선택한다.
**Independent Test**: 한 카드를 다시 본 뒤 완료 화면에서 카드 수가 중복 집계되지 않는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 마지막 응답을 저장했을 때, **When** 세션이 끝나면, **Then** 복습한 카드 수·알고 있어요 수·다시 볼 카드 수를 확인한다.
2. **Given** 완료 화면일 때, **When** 홈으로 또는 학습방으로 돌아가기를 누르면, **Then** 해당 화면으로 이동한다.

### User Story 3 - 실제 복습 현황 확인 (Priority: P2)

홈과 카드 화면에서 오늘 복습할 카드 수, 저장한 표현 수, 누적 정답률을 확인한다.
**Why this priority**: 고정된 숫자가 실제 복습 상태로 오인되는 문제를 없앤다.
**Independent Test**: 표현 저장·응답 후 두 화면의 숫자를 비교한다.

**Acceptance Scenarios**:

1. **Given** 기록이 없을 때, **When** 홈을 열면, **Then** 정답률 대신 아직 기록이 없어요를 본다.
2. **Given** 저장한 표현이 없을 때, **When** 복습 영역을 보면, **Then** 표현 저장 방법과 학습방 진입 수단을 본다.
3. **Given** 모든 카드가 미래에 예정돼 있을 때, **When** 복습 영역을 보면, **Then** 오늘 복습할 카드가 없어요와 가장 빠른 예정일을 본다.
4. **Given** 저장소가 차단됐을 때, **When** 현황을 보면, **Then** 0장으로 표시하는 대신 실패와 재시도 수단을 본다.

### Edge Cases

- 21개 이상이면 예정일이 오래된 순으로 20개만 시작한다. 홈의 수는 세션 제한 전 전체 대상 수다.
- 예정일 동률은 저장 시각, 표현 id 순이다. 새 표현은 저장한 로컬 날짜를 예정일로 본다.
- 날짜 경계는 기기의 로컬 날짜이며 월말·연말·서머타임에서도 달력 날짜로 더한다.
- 깨진 기록만 버리고 유효한 기록을 사용한다. 삭제한 표현의 고아 기록은 집계에서 제외한다.
- 쓰기 실패 시 카드와 앞선 응답을 유지하며 성공으로 진행하지 않는다. 재시도하면 같은 응답이 한 번만 저장된다.
- 세션 중 삭제된 표현에는 응답을 저장하지 않고 해당 카드를 건너뛴다.
- 긴 표현·뜻·예문은 줄바꿈하며 컨트롤을 가리지 않는다.

## Requirements

### Functional Requirements

- **FR-001**: 새 표현은 즉시 대상이며 다음 시점이 오늘 이전 또는 오늘인 카드만 복습 대상으로 선택한다. 세션당 최대 20개, 예정일·저장 시각·id 오름차순이다.
- **FR-002**: 앞면은 표현, 뒤에는 뜻·예문·출처 학습방을 보인다. 뒤집은 뒤 알고 있어요/다시 볼래요를 선택한다. 소리가 없는 재생 버튼은 제공하지 않는다.
- **FR-003**: 알고 있어요 간격은 최초 1일, 이후 직전 간격의 두 배(최대 30일)다. 다시 볼래요는 간격을 1일로 되돌리고 다음 시점을 오늘로 정한다. 날짜 기준은 로컬 달력이다.
- **FR-004**: 첫 순회에서 다시 볼래요로 응답한 카드는 세션 끝에 한 번 더 나온다. 재등장 응답으로 재추가하지 않는다.
- **FR-005**: 응답마다 즉시 영속 저장한다. 중도 이탈 시 저장된 응답은 남고 세션 자체는 재개하지 않는다.
- **FR-006**: 표현과 분리된 복습 기록은 표현 id로 연결한다. 표현의 뜻·예문을 수정하지 않으며 삭제된 표현 기록은 읽을 때 버린다.
- **FR-007**: 저장소를 읽기 전에는 대기를, 접근 실패에는 실패 안내와 재시도를 보인다. 잘못된 항목은 버리고 나머지를 사용한다. 저장 실패 시 진행·집계를 성공처럼 바꾸지 않는다.
- **FR-008**: 완료 화면은 고유 카드 수와 각 카드의 최종 응답 기준 알고 있어요 수·다시 볼 카드 수만 보이며 홈/학습방으로 이동한다.
- **FR-009**: 홈과 카드 화면은 전체 오늘 대상 수와 복습 진입을 제공한다. 대상이 없으면 버튼 대신 이유와 다음 예정일 또는 표현 저장 방법을 안내한다.
- **FR-010**: 홈은 실제 표현 수와 누적 알고 있어요 응답 수/전체 응답 수의 정답률을 보인다. 응답 0회는 아직 기록이 없어요다. 대화한 날은 제거하고 전체 보기는 카드 화면으로 이동한다.
- **FR-011**: 모든 새 컨트롤은 키보드로 조작 가능하고 아이콘에는 라벨, 뜻 영역에는 열림 상태와 연결을 제공한다. 전환 후 포커스는 다음 카드 또는 완료 제목으로 이동하고 상태는 보조기기에 알린다.
- **FR-012**: 쓰기 전에 최신 저장 기록과 표현 목록을 다시 읽어 다른 응답을 보존하며, 삭제된 표현을 되살리지 않는다.

### Key Entities

- **표현**: 상류에서 저장한 본문·뜻·예문·출처. 복습은 읽기만 한다.
- **카드**: 표현 하나와 다음 복습 시점·간격·누적 응답 수의 결합이다.
- **복습 세션**: 선택한 카드, 현재 위치, 한 번의 재등장 목록, 카드별 최종 응답을 가진 일시 상태다.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 뜻 보기와 기억 여부 선택 두 번의 조작으로 카드 한 장의 응답을 마친다.
- **SC-002**: 세션은 고유 카드 20개, 재등장을 포함한 응답 최대 40회 내에 종료한다.
- **SC-003**: 완료 화면의 두 응답 수 합계는 복습한 고유 카드 수와 일치한다.
- **SC-004**: 새로고침 후에도 응답과 다음 시점이 유지되고 홈과 카드 화면의 대상 수가 일치한다.
- **SC-005**: 키보드만으로 진입·뜻 보기·응답·결과 확인·복귀를 모두 완료한다.

## Assumptions

- 브라우저 간 동기화·로그인·알림·음성 재생·표현 편집은 범위 밖이다.
- 완료 통계는 카드별 마지막 응답, 누적 정답률은 재등장 응답까지 모두 센다. 정답률은 정수 반올림한다.
- 응답은 사용자의 명시적 선택이며 삭제/전송이 아니므로 추가 확인 없이 기록한다. 중도 이탈은 미응답만 버리므로 확인 없이 나간다.
- 동시 탭의 완전히 같은 순간 쓰기에 대한 트랜잭션 보장은 제공하지 않는다.
