# Quickstart: 저장한 표현 복습 검증

**Feature**: [spec.md](./spec.md) | **Date**: 2026-10-27

## 실행

Node.js20 이상. `npm.cmd install`, `npm.cmd run dev` 후 localhost:3000 접속.
학습방 스크립트에서 표현 2개 이상을 저장한다. 저장소 초기화는 별도 프로필에서 한다.
빌드 게이트 `npm.cmd run build`. 브라우저 표는 별도 검증자 인계용이며 수행 완료를 주장하지 않는다.

## 실행 결과 (2026-10-27)

- `npm.cmd run build` 통과, TypeScript 오류 0개.
- 저장소·스케줄·재등장 순수 로직 53개 assertion을 Asia/Seoul 및 America/New_York에서 각각 통과.
  월말·연말·윤년·DST, 1→2→4→8→16→30 상한, 리셋, 손상/고아 필터,
  쓰기 실패 불변·재시도·최신 읽기 병합, 최대40회 종료 및 최종 응답 집계를 확인했다.
- `git diff --check` 통과. 브라우저 수동 검증은 사용자 지시에 따라 수행하지 않았다.
