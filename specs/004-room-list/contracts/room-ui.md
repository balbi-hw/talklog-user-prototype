# Contract: 학습방 화면과 셸

**Feature**: [spec.md](../spec.md)

1. RoomList/RoomSummary는 셸에서 정렬한 학습방·메시지 요약을 받는다. 홈은 처음 3개다.
2. 표시 이름·학습 짝·언어·메시지 수·마지막 시각(있으면)을 표시하고 예시는 식별한다.
3. loading 대기, unavailable 실패 안내·마지막 정상 목록·재시도, ready 사용자 항목 0개는 개설 안내를 표시한다.
4. RoomCreate는 라벨 있는 이름·언어 입력, 오류 이유, 실패 초안 유지·재시도, 취소를 제공한다. 초대·알림·실제 전달 미구현을 알린다.
5. 삭제 확인은 aria-expanded/controls 연결, 이름·메시지 소멸·표현 보존 안내. 진입은 취소, 취소는 삭제 버튼, 성공은 목록 제목 포커스다.
6. 개설 후 학습방 제목, 목록 진입·개설 취소 후 목록 제목, 개설 진입 후 입력에 포커스. 상태는 role=status다.
7. 대화 메뉴는 목록, 학습방의 목록 복귀는 기존 녹음 이탈 확인을 거친다.
8. Room은 선택한 학습방의 메시지만 받는다. 예시에서만 스크립트·번역·피드백, sourceRoom은 roomName(room). 새 학습방은 빈 안내·녹음을 제공한다.
9. 삭제 성공 후 메시지 제거·URL 해제. 앱 언마운트에도 전송 URL 정리. 저장한 표현은 변경하지 않는다.
