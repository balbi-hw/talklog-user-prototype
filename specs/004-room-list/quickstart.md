# Quickstart: 학습방 목록·개설 검증

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-10-27

## 사전 조건·실행

Node.js 20 이상, npm.cmd install, npm.cmd run dev 후 localhost:3000. 녹음은 localhost 또는 HTTPS와 마이크가 필요하다. 빌드 게이트 npm.cmd run build는 TypeScript 오류 0개여야 한다. 브라우저 수동 검증은 요청에 따라 별도 검증자가 수행한다.
