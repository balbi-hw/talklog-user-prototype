# Quickstart: 카드 편집 검증

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-10-27

## 사전 조건과 실행

Node.js 20 이상. 기존 002 흐름으로 서로 다른 표현 3개를 저장한다.
홈 → 대화 → 스크립트에서 범위 선택 → 뜻 입력 → 저장 후 하단 카드 메뉴로 이동한다.
Feedback의 예시 표현을 저장해도 된다. 저장소 키는 `talklog.expressions`다.

```powershell
npm.cmd install
npm.cmd run dev
# 빌드 게이트
npm.cmd run build
```

브라우저는 http://localhost:3000 에서 연다. 테스트 데이터 변경 전에 기존 저장소 값을
복사해 둔다. 아래 수동 시나리오는 사용자 지시에 따라 별도 검증자가 수행한다.

## S1. 기록 보존·저장·취소 (US1)

| # | 조작 | 기대 결과 | 요구사항 |
|---|---|---|---|
| 1 | 카드의 편집을 누른다 | 항목 안에 원래 본문·뜻과 저장·취소, 뜻 입력칸에 포커스 | FR-001, FR-013, SC-001 |
| 2 | 뜻만 고쳐 저장한다 | 자신을 중복으로 보지 않고 즉시 반영, 완료 알림, 편집 버튼에 포커스 | FR-004, FR-007, SC-004 |
| 3 | 본문도 고쳐 저장한다 | 새 본문과 뜻이 보이고 예문·출처는 그대로 | FR-003 |
| 4 | 순서·개수와 저장소의 id·savedAt을 이전 값과 비교한다 | 모두 유지 | FR-009, SC-002 |
| 5 | 새로고침 후 카드 목록을 연다 | 수정값과 원래 예문·출처·순서 유지 | FR-004, SC-002 |
| 6 | 다시 편집하고 값을 바꾼 뒤 취소한다 | 값이 저장되지 않고 편집 버튼에 포커스 | FR-005, FR-013 |
| 7 | 편집 중 다른 화면에 갔다 돌아온다 | 저장 전 값, 편집 폼 닫힘 | FR-005 |

## S2. 검증과 중복 (US2)

| # | 조작 | 기대 결과 | 요구사항 |
|---|---|---|---|
| 1 | 표현을 공백 또는 `？！`로 바꾼다 | 표현 안내, 저장 비활성 | FR-006, FR-008, SC-003 |
| 2 | 뜻을 공백만 남긴다 | 뜻 안내, 저장 비활성 | FR-006, FR-008 |
| 3 | 다른 저장 표현과 같은 본문을 입력한다 | 중복 안내, 저장 비활성 | FR-007 |
| 4 | 다른 표현이 `が`일 때 `か`와 결합 탁점(U+3099)을 입력하고 앞뒤 공백을 넣는다 | NFC 정규화 중복으로 막힘 | FR-007 |
| 5 | 본문을 원래대로 두고 뜻만 고친다 | 저장 가능 | FR-007 |
| 6 | 본문·뜻 앞뒤 공백을 넣어 저장한다 | 저장값은 trim, 예문·출처는 변경 없음 | FR-003, FR-006 |

## S3. 실패·재시도·최신 저장소 (US3)

쓰기 실패는 DevTools에서 `Storage.prototype.setItem`을 임시로 예외를 던지게 하고
원래 함수를 보관해 복원한다. 읽기 실패는 getItem도 같은 방식으로 재현한다.

| # | 조작 | 기대 결과 | 요구사항 |
|---|---|---|---|
| 1 | 편집 중 쓰기만 실패시키고 저장한다 | 실패 알림, 목록 원래 값, 입력값·폼 유지, 성공 안내 없음 | FR-010, SC-003 |
| 2 | 함수를 복원하고 새로고침 없이 저장한다 | 입력을 다시 적지 않고 성공, ready 복귀 | FR-010, SC-005 |
| 3 | 읽기를 실패시킨 상태에서 저장한다 | 쓰지 않고 실패, 입력 유지 | FR-010 |
| 4 | 편집 시작 후 콘솔에서 저장소 배열에 다른 표현을 추가하고 저장한다 | 추가 항목 보존 | FR-011 |
| 5 | 편집 시작 후 저장소에 편집 예정 본문과 같은 다른 표현을 추가하고 저장한다 | 중복 안내, 쓰지 않음, 입력 유지 | FR-007, FR-011 |
| 6 | 편집 시작 후 콘솔에서 대상 id를 삭제하고 저장한다 | 대상 없음 안내, 재생성 안 됨, 취소 가능 | FR-011 |
| 7 | 편집 시작 후 저장소 대상의 예문·출처만 바꾸고 저장한다 | 최신 예문·출처 보존, 본문·뜻만 변경 | FR-003, FR-011 |
