# Quickstart: 학습 짝 초대와 음성 메시지 주고받기

## 준비
- `npm run build` 두 번: `.env.local` 의 키가 있을 때와 없을 때. 둘 다 성공해야 한다.
- 자동 검증: 가짜 Auth·PostgREST·Storage·Realtime 으로 브라우저 문맥 A(계정 1)와 B(계정 2)를 띄운다(research R10). 실제 계정을 만들지 않는다.
- 실제 DB: `supabase/migrations/20261103010000_partner_messages.sql` 을 SQL Editor 에서 실행한다. 사용자가 직접 만든 두 계정을 쓴다.

## 자동 항목 (가짜 서버)
| # | 시나리오 | 기대 |
| --- | --- | --- |
| P1 | A: 학습방 → 초대 코드 만들기 | 6자 코드·남은 시간·복사 버튼. 코드 글자가 허용 목록 안 |
| P2 | B: 목록 → 초대 코드 입력 → 확인 → 들어가기 | 만든 사람 이름·학습 언어 확인, 학습방이 열리고 목록에 있다 |
| P3 | A 화면 | 실시간으로 학습 짝 이름이 보이고 코드가 사라진다 |
| P4 | 형식 틀림·없음·만료·사용됨·내 학습방·학습 짝 있음·너무 많이 시도함·오프라인·시간 초과 | 각각 다른 문구, 들어가지 않음 |
| P5 | 코드 취소·새로 만들기 뒤 옛 코드 | `not-found` 또는 취소 문구 |
| P6 | A: 녹음 → 전송 | "보내는 중" → 보낸 시각. B 화면에 5초 안에 학습 짝 메시지 |
| P7 | B: 그 메시지 재생, 스크립트 → 번역 → 표현 저장 | 재생됨, 007·002 흐름 그대로. 다듬기 버튼 없음 |
| P8 | 올리기 실패(500)·오프라인 | "보내지 못했어요", 다시 보내기 → 한 번만 놓임, 지우기 → 사라짐 |
| P9 | 행 넣기 응답만 잃음(서버에는 있음) → 다시 보내기 | 중복 0 |
| P10 | 실시간 끊김 → 그사이 메시지 → 복구 또는 창 복귀 | 안내와 다시 시도, 빠진 메시지가 순서대로 한 번 |
| P11 | 새로고침 | 메시지가 같은 순서로 다시 보이고 재생된다 |
| P12 | B: 학습방 지우기 → 확인 | B 목록에서 사라짐. A 에 "학습 짝이 나갔어요", 녹음 영역 막힘, 지난 메시지 보임 |
| P13 | A 도 지우기 | 소리 지우기 요청 → 나가기, 공유 정보 삭제 |
| P14 | 나가기 중 오프라인 | 지우지 않고 이유를 알림 |
| P15 | 로그아웃 | 공유 학습방·메시지가 사라지고 localStorage 에 새 키 없음, 채널 닫힘 |
| P16 | 로그아웃 상태·키 없는 빌드 | 001~010 흐름 회귀 없음, 초대 자리에 로그인 안내, 외부 요청 0 |
| P17 | 예시 학습방 | 예시 메시지 그대로, 초대 자리 없음 |
| P18 | 키보드만으로 P1·P2·P6·P12 | 모두 가능, 대화상자 포커스·Escape, 상태 문구 role=status |
| P19 | 보내는 중에 다른 화면으로 | 떠나기 확인 |
